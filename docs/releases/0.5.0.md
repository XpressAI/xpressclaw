# XpressClaw 0.5.0

XpressClaw 0.5.0 introduces the Spatial Canvas workspace: a new way to arrange
Projects, Tasks, Conversations, files, terminals, and previews together on a
canvas. This stable release promotes prerelease `0.4.58`, rebuilding Desktop
and standalone CLI packages as `0.5.0` while retaining native build `58` and
that prerelease's tested Agent runner images.

Since the previous stable release, `0.4.35`:

- **Spatial Canvas:** switch between Tabs and Canvas, pan and zoom, and arrange
  draggable, resizable windows around your work. Project cards open related
  Tasks, Conversations, files, and terminals. Live links show delegation and
  dependencies; grid snapping, Tidy, Fit, and a minimap help organize the view.
  Canvas and tab layouts are saved independently.
- **Previews beside the conversation:** file links, images, HTML attachments,
  and web links in Task, Conversation, and Agent windows can open in Canvas
  editors and viewers. Preview windows stay linked to their source window;
  Ctrl/Command-click opens or downloads directly.
- **Inline diagrams:** Mermaid diagrams render in messages, including diagram
  output shared by Agents.
- **Faster live updates:** revision-based updates and incremental refreshes
  reduce repeated data transfers while keeping Tasks and Conversations current
  on slower connections.
- **Agent sign-in and recovery:** complete supported Agent sign-in flows inside
  XpressClaw and retry the failed task. Retries retain the original instructions
  and attachments. Dismissed error banners stay dismissed across navigation and
  reloads, and newer attempts clear obsolete failures.
- **More Agent runners:** Antigravity and Jouzu join the runner catalog, with
  updated harness versions and model discovery. Antigravity can start
  Conversations after authentication.
- **Agent network controls:** configure the instance proxy and per-Agent direct
  connections, domain rules, and request headers from Settings.
- **Project navigation and storage:** breadcrumbs retain Project context, All
  Tasks stays scoped to the selected Project, and storage previews help identify
  and remove selected retained Project data.
- **Runtime reliability:** transient runner failures retry automatically,
  preparation and dispatch recover more reliably, and Xpress AI connection
  diagnostics expose synchronization failures.
- **Windows compatibility:** external tools and displayed paths use standard
  drive and UNC paths while filesystem checks retain canonical paths.

Install the latest stable standalone CLI/server:

```bash
curl -fsSL https://raw.githubusercontent.com/XpressAI/xpressclaw/main/install.sh | sh
```

Existing instances retain their configuration and data. Stop the existing
instance before replacing its executable, then start it with the same instance
directory. Database migrations run at startup.
