# XpressClaw 0.4.26

This stable release promotes the code tested in prerelease `0.4.25`. Desktop
and standalone CLI packages are rebuilt as `0.4.26`, with Agent runner images
pinned to the same revision used by that prerelease.

Since the previous stable release, `0.4.13`:

- **Better mobile editing:** background updates no longer move the page while
  you type, select text, or paste. The workspace fits above the software keyboard,
  makes more room for the composer, and keeps Send reachable on smaller screens.
- **Delegated tasks in task details:** delegated work appears beside plan steps
  in the right sidebar, or the Task details sheet on mobile. Completed work stays
  collapsed there. Active blockers, failures, and saved replies remain visible,
  and resolved delegation alerts clear when the work resumes.
- **More reliable model controls:** model, mode, and reasoning selections use the
  harness's advertised options. Explicit task preferences persist, while pending
  changes remain distinguishable from the Agent's current settings.
- **Preserved Agent environments:** harness updates and settings recovery retain
  installed dependencies and existing work. Incompatible images are identified,
  and environment rebuilding remains an explicit action.
- **Xpress AI Connect:** optionally pair an installation with a compatible
  Xpress AI platform, authorize projects, and run their chats and tasks through
  local Agents. Platform work retains its upstream ownership and scheduling.
- **Updated Agent harnesses:** refreshed runner versions and improved handling
  of transient Claude OAuth refresh conflicts.

Install the latest stable standalone CLI/server:

```bash
curl -fsSL https://raw.githubusercontent.com/XpressAI/xpressclaw/main/install.sh | sh
```

Existing instances retain their configuration and data. Stop the existing
instance before replacing its executable, then start it with the same instance
directory. Database migrations run at startup.
