# XpressClaw 0.4.13

This stable release promotes the code tested in prerelease `0.4.11`. Desktop
and standalone CLI packages are rebuilt as `0.4.13`, with Agent runner images
pinned to the same revision used by that prerelease.

Since the previous stable release, `0.3.0`:

- **Speech input and read-aloud:** configure an OpenAI-compatible audio endpoint,
  API key, models, and voice in **Settings → Speech**. Dictation fills your draft
  for review before sending; **Read aloud** plays an Agent reply when you choose
  it. Speech is optional and disabled by default.
- **Installable mobile web app:** add XpressClaw to your home screen, with improved
  keyboard handling, safe-area spacing, and recovery from temporary cache failures.
- **More reliable workspace tabs:** ordinary clicks stay clicks, touch flicks
  scroll the tab strip, and abandoned drags restore the workspace correctly.
- **Clearer messages and file downloads:** inline Markdown renders inside lists;
  Agent file links preserve download names and handle source line references.
- **Updated Agent harnesses:** refreshed runner versions, bounded ACP smoke-test
  cleanup, and tested pins for Qwen and DeepSeek versions that failed newer smoke
  tests. macOS Podman setups now explain unsupported SSH-agent forwarding.

Install the latest stable standalone CLI/server:

```bash
curl -fsSL https://raw.githubusercontent.com/XpressAI/xpressclaw/main/install.sh | sh
```

Existing instances retain their configuration and data. Stop the existing
instance before replacing its executable, then start it with the same instance
directory. Database migrations run at startup.

Speech sends recordings and text to the endpoint you configure. Microphone
recording requires browser permission and a secure context (HTTPS or localhost).
See [Speech setup and usage](https://github.com/XpressAI/xpressclaw/blob/v0.4.13/docs/speech.md).
