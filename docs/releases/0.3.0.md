# XpressClaw 0.3.0

The first stable XpressClaw release promotes the functionality tested in
prerelease `0.2.123`. Desktop and standalone CLI packages are rebuilt with
version `0.3.0`; Agent runners stay pinned to the images used by that prerelease.

XpressClaw is a local control plane for coding agents, with a shared workspace
for managing work across projects, agents, and conversations.

- Plan work in Board, Timeline, or List views. Park ideas in Backlog, assign
  priorities, manage dependencies, and set a durable “Start no earlier than” time.
- Keep mobile work focused with modal navigation and compact task controls.
- Connect local services to agent containers and expose container services on
  host loopback ports. Browse, upload, publish, and download files and folders;
  share interactive tmux sessions through the Files terminal.
- Monitor server CPU, memory, and disk capacity in Control Center. Follow agent
  updates and responses, and see reported token totals alongside context usage.
- Run native ACP harnesses with retained containers, durable tasks, scheduled
  work, workflows, and managed GitHub review follow-up.

Token totals reflect available per-response reports from Claude and Codex;
missing or unsupported reports are shown explicitly. Resource meters describe
the environment running the XpressClaw server.

The default standalone installer now selects this stable release:

```bash
curl -fsSL https://raw.githubusercontent.com/XpressAI/xpressclaw/main/install.sh | sh
```

Existing instances retain their configuration and data. Stop the existing
instance before replacing its executable, then start it with the same instance
directory. Database migrations run at startup.
