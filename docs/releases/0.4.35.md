# XpressClaw 0.4.35

This stable release promotes prerelease `0.4.34`. Desktop and standalone CLI
packages are rebuilt as `0.4.35`, retaining that prerelease's native build
number and tested Agent runner images.

Since the previous stable release, `0.4.26`:

- **Project manager Agents:** discover teammates and their exact IDs, inspect
  task results, and create up to 100 tasks or workflows in one batch. Plans can
  include assignments, dependencies, Backlog holds, future starts, one-time
  workflows, and recurring schedules. Managers can release work, pause it,
  and reschedule it as the project progresses.
- **Durable workflow plans:** Project-owned workflows remain private to their
  Project, survive moving its last Agent, and retain their ownership through
  Project synchronization, including plans that have not run yet. Deletion
  previews include owned workflows and require explicit confirmation.
- **Parallel alternatives:** the new “Implement alternatives → choose best”
  workflow builds isolated implementations, checks them against a shared rubric,
  and selects a passing candidate. An optional refinement pass adopts ideas
  from the other implementation when the result passes checks and scores higher.
  The visual editor supports parallel groups and command verification.
- **Adaptive workspaces:** panes and details respond to the available space on
  foldable and smaller displays. Layout changes preserve drafts, text selection,
  transcript position, and unsaved file edits.
- **External links:** links outside XpressClaw, including terminal links, open
  in the user's default browser from the Desktop app.
- **Reliable macOS runners:** rootful macOS containers retain their image's user,
  fixing OpenCode startup permission errors while preserving existing files.
- **Clearer runner preparation and upgrades:** compatible retained environments
  remain ready without unnecessary downloads. Preparation shows elapsed time
  and persistent errors, while a subtle notice identifies downloaded harness
  upgrades and links to their settings.

Install the latest stable standalone CLI/server:

```bash
curl -fsSL https://raw.githubusercontent.com/XpressAI/xpressclaw/main/install.sh | sh
```

Existing instances retain their configuration and data. Stop the existing
instance before replacing its executable, then start it with the same instance
directory. Database migrations run at startup.
